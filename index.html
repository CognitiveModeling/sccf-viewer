Pretraining

Runs phase 1 of the paper silently (learn_contexts.py: 4 × 640 trials, exact inference), then applies the resets of perform_tasks.py: θ back to a sticky prior, cprev to the value below. Seed sets the pretraining run too.

Inference

Goal inference also conditions on i = task (instruction=True). Context ck is assumed to go with task k (c0 ink, c1 word), so the cue needs 2 contexts.

Steps after the response
World-model structure

As in inference_illustration.py: the twin uses c0's CPDs (or, with pretraining, the 1-context model pretrained alongside), and p(K) is updated each trial from the difference in surprise.

Off while the instruction cue is on: a 1-context model has no cue node (the Python code would fail too).

Model (model_config.py)

With pretraining, α, β and the number of contexts come from the pretrained model. Stickiness, θ strength and the initial cprev set the θ reset (paper: 0.99, 0.5, 0.5).
