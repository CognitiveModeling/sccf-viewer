Notes on the code (behaviour reproduced as written)
  • The sampler starts its counts at 1 for every (a, c), so iteration 0 is uniform, not the prior. Its iteration-0 error is computed under the prior (sampler.py).
  • On the first trial, habit and task-set learning put all counts on context c0 (first_trial branches), which breaks the symmetry between contexts.
  • Outcome inference conditions on the chosen action, but its error term averages p(o|c,s,a) over the action belief goal_posterior_a.
  • After outcome inference the network is rebuilt with a uniform cprev, so the re-computed surprise in learn_habit (overall_goal_surprise) uses a uniform context-transition prior on those trials.
  • Learning costs use torch.distributions.Dirichlet, which treats the last array axis as the event axis (s1 for α, a for β, s0 for θ). The CPDs are normalised over the first axis (a, o, c). So the reported KL is taken over a different axis than the one the probabilities live on.
